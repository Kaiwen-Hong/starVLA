  World frame 和 Base frame 的关系

  因为 R_bw = I（旋转矩阵是单位阵），两个坐标系的轴完全对齐，只差一个平移：

  pos_world = pos_base + offset
  pos_base  = pos_world - offset
                                
  left arm offset: [+0.80, -0.22, +0.02]
                                        
  所以 clamp 在 world frame 做完全等价于在 base frame                           
  做（范围平移一下而已）。比如 world frame y ∈ [-0.55, -0.15] 等于 base frame y 
  ∈ [-0.55 - (-0.22), -0.15 - (-0.22)] = y ∈ [-0.33, +0.07]。
